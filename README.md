# ocean_portfolio

A cinematic, ocean-inspired portfolio for Akash Gojuru, a Computer Engineering student
at Iowa State heading into ASIC and chip design. The idea is that his engineering work
and his love of the ocean belong to one world, instead of a tech site with a water theme
on top.

**Status:** design phase. There is no code yet.

## Why
His current site is a standard template. This project is an alternative, award-level
direction. It should get a hardware recruiter to open his resume or reach out.

## Docs
- [`docs/vision.md`](docs/vision.md): the vision and the decisions already made
- [`docs/content.md`](docs/content.md): real content inventory (source of truth)
- `docs/design/`: the design team's brief, concept, UX, art, motion, critique and final plan

## Run
Nothing to run yet. The planned stack is Three.js / React Three Fiber, GSAP ScrollTrigger
and Lenis.
